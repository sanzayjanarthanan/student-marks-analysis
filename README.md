# Student Marks Analysis

## Problem
Analyze student marks and calculate the total, average, highest and lowest marks using Python.

## Approach
- Stored student marks in a Python dictionary
- Extracted the marks into a list
- Used `sum()`, `max()` and `min()` for total, highest and lowest
- Calculated average as total ÷ number of students

## Sample Output
Total   : 448
Average : 74.67
Highest : 92 (Priya)
Lowest  : 54 (Rahul)

## How to Run
1. Open `Student_Marks_Analysis.ipynb` in Jupyter Notebook or Google Colab
2. Run all cells

## Tools
Python, Jupyter Notebook
